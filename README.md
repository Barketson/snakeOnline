# Neon Snake — онлайн-змейка с мультиплеером

Неоновая аркадная змейка для браузера: до **8 игроков** в одной комнате,
авторитарный сервер на Node.js + `ws`, клиент — чистые ES-модули, HTML, CSS
и `<canvas>` без фреймворков и сборщиков.

## Как играть

- Введите ник (1–16 символов) и нажмите **«Создать комнату»** — вы станете хостом.
- Друзья открывают **ссылку с кодом** (`http://<ваш-ip>/?room=CODE`) или вводят
  5-символьный код на главном экране.
- Хост запускает раунд кнопкой **«Начать игру»**. Перед стартом — отсчёт 3-2-1.
- Управление: **стрелки** или **WASD**. Разворот на 180° запрещён.
- Еда — +10 очков и +1 к длине. Смерть — от стены, своего или чужого тела,
  лоб в лоб гибнут обе змейки.
- Раунд длится 3 минуты или пока не останется ≤ 1 выжившего. В конце —
  места по очкам и общий счёт за сессию.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Игра с друзьями в одной сети

1. Запустите сервер (`npm start`) и откройте порт 3000 в файерволе Windows
   (Панель управления → Брандмауэр → Разрешение приложений → Node.js,
   или `netsh advfirewall firewall add rule name="Snake" dir=in action=allow protocol=TCP localport=3000`).
2. Узнайте свой локальный IP:
   - Windows: `ipconfig` → «Адаптер беспроводной локальной сети» → IPv4-адрес;
   - Linux: `ip a` → адрес интерфейса (например, `192.168.x.x`).
3. Поделитесь ссылкой вида `http://192.168.x.x:3000/?room=CODE`, где `CODE` —
   код комнаты из лобби. Друзья открывают её в браузере, вводят ник и попадают
   в ту же комнату.

## Деплой

### Render

1. Залейте репозиторий на GitHub/GitLab.
2. На https://render.com: **New → Web Service** → выберите репозиторий.
3. Настройки: **Runtime** = Node, **Build Command** = `npm ci --omit=dev`,
   **Start Command** = `npm start`.
4. Добавьте переменную окружения `PORT` со значением `3000` (Render по умолчанию
   сам задаёт `PORT`; оставьте как есть, сервер читает `process.env.PORT`).
5. Deploy — Render выдаст публичный `https://…` URL. HTTPS работает из коробки:
   клиент сам переключается на `wss://`.

### Fly.io

1. Установите `flyctl` и выполните `fly auth login`.
2. В корне проекта: `fly launch` (ответьте на вопросы; приложение создастся
   по `Dockerfile`).
3. Если нужно — поправьте `fly.toml`: внутренний порт должен быть `3000`:
   ```toml
   [[services.ports]]
     internal_port = 3000
   ```
4. `fly deploy`.
5. Для публичного доступа включите HTTPS (по умолчанию Fly выдаёт TLS-сертификат
   и `https://…` URL — WebSocket через `wss://` работает автоматически).

## Docker

```bash
docker build -t neon-snake .
docker run -p 3000:3000 neon-snake
```

`Dockerfile` использует `node:20-alpine` и `npm ci --omit=dev` (только
production-зависимости).

## Что можно добавить дальше

- **Бонусы** на поле (ускорение/замедление, двойные очки) — серверная логика
  в `game.js` изолирована, события расширяемы;
- **Чат в лобби** — новый тип сообщения по существующему контракту;
- **Мобильное управление** — свайпы/экранный джойстик поверх текущего `input`;
- Лидерборды, настройки раунда (длительность, скорость), зрители с подсветкой.
